# FIGHTGROUNDS 업데이트 기획

## v1.1 — 이번 업데이트 (이 PR에 구현)

| 항목 | 내용 | 목적 |
| --- | --- | --- |
| **AI 난이도 선택** | 로비에서 쉬움 / 보통 / 어려움 선택. 봇의 조준 정확도·반응 속도·시야 인지가 함께 바뀜 | 초보자는 쉽게, 숙련자는 도전적으로 |
| **보급품 공중 투하** | 자기장 2~4단계가 시작될 때 다음 안전 구역 안으로 낙하산 상자가 떨어짐. 빨간 연기와 지도 아이콘으로 표시. 안에는 저격총·DMR·고급 소총 중 하나와 탄약, Lv.3 방어구, 구급상자, 드링크, 수류탄 | 중후반 교전 유도, 역전 기회 |
| **스코프(조준경)** | 레드닷·2배·4배·8배 4종을 루팅해 소총·SMG·산탄총에 장착. 4배 이상은 전체 화면 조준경 시점. 보급품에는 4배 또는 8배가 반드시 포함 | 원거리 교전 선택지와 루팅 동기 |
| **피해량 숫자** | 내가 맞힌 적 머리 위에 피해량이 떠오름(헤드샷은 주황색) | 타격감과 무기 성능 체감 |

### 세부 규칙
- **난이도 수치**: 봇 스킬 = 기본값 × 배율 + 보정 (쉬움 ×0.7−0.05, 보통 ×1, 어려움 ×1.1+0.12). 사격 반응 시간은 쉬움 1.6배, 어려움 0.7배.
- **보급품**: 투하 고도 190m, 초당 7.5m 하강(약 25초). 착지하면 상자는 엄폐물이 되고 아이템이 주변에 흩어짐. 착지 소리가 260m 안의 봇을 끌어들임.
- 난이도 선택은 브라우저에 저장되어 다음 접속에도 유지됨.
- **스코프**: 레드닷 1.3배, 2배, 4배, 8배. 권총은 장착 불가. 줍으면 현재 들고 있는 주무기부터 더 높은 배율일 때만 자동 장착하고, 기존 스코프는 바닥에 떨굼. DMR·저격총의 기본 조준경(3.2배·5.5배)보다 낮은 배율은 장착하지 않음. 무기를 바꿔 들어도 스코프는 새 무기로 옮겨짐. 무기 이름 옆에 배율 표시.

## v1.2 — 오토 기능 & FPS 편의 기능 (이 PR에 구현)

| 항목 | 조작 | 내용 |
| --- | --- | --- |
| **오토 플레이** | `P` / 모바일 `오토` 버튼 | AI가 캐릭터를 대신 조종(강하·루팅·회복·자기장 이동·교전). 카메라는 AI 시선을 따라감. 다시 누르면 그 자리에서 직접 조작으로 복귀. 사망 시 자동 해제 |
| **자동 사격** | 설정 탭 / 일시 정지 메뉴 | 조준점이 사거리 안의 적에게 닿으면 자동 사격. 단발 무기는 최소 0.22초 간격. 모바일 기본 켜짐, PC 기본 꺼짐 |
| **자동 달리기** | `=` / 모바일 스틱을 위로 길게 끌기 | 손을 떼도 앞으로 달림. PC는 W·S, 모바일은 스틱을 다시 잡으면 해제 |
| **사격 모드 전환** | `B` / 모바일 `연사·단발` 버튼 | 연사 가능한 총(SMG·소총)을 단발로 전환. 무기마다 따로 기억, 탄약 옆에 표시 |
| **기울이기** | `Q` / `E` | 엄폐물 옆으로 몸·카메라·총구를 기울임. 벽에 막히면 덜 기울어짐. 머리 판정도 함께 이동 |
| **자유 시점** | `Alt` 누르고 있기 | 이동 방향은 그대로 두고 카메라만 돌려 주변 확인. 떼면 원래 시점으로 복귀(사격·조준 불가) |
| **핑** | 휠 클릭 / 모바일 `핑` 버튼 | 조준점 위치에 노란 마커와 거리 표시, 미니맵에도 표시. 같은 곳을 다시 찍으면 제거 |
| **소리 방향 표시** | 자동 | 36m 안 발소리(흰 발자국)와 들리는 범위의 총성(주황 화살표)을 조준점 둘레에 방향으로 표시 |
