# FIGHTGROUNDS 업데이트 기획

## v1.1 — 이번 업데이트 (이 PR에 구현)

| 항목 | 내용 | 목적 |
| --- | --- | --- |
| **AI 난이도 선택** | 로비에서 쉬움 / 보통 / 어려움 선택. 봇의 조준 정확도·반응 속도·시야 인지가 함께 바뀜 | 초보자는 쉽게, 숙련자는 도전적으로 |
| **보급품 공중 투하** | 자기장 2~4단계가 시작될 때 다음 안전 구역 안으로 낙하산 상자가 떨어짐. 빨간 연기와 지도 아이콘으로 표시. 안에는 저격총·DMR·고급 소총 중 하나와 탄약, Lv.3 방어구, 구급상자, 드링크, 수류탄 | 중후반 교전 유도, 역전 기회 |
| **스코프(조준경)** | 레드닷·2배·4배·8배 4종을 루팅해 소총·SMG·산탄총에 장착. 4배 이상은 전체 화면 조준경 시점. 보급품에는 4배 또는 8배가 반드시 포함 | 원거리 교전 선택지와 루팅 동기 |
| **피해량 숫자** | 내가 맞힌 적 머리 위에 피해량이 떠오름(헤드샷은 주황색) | 타격감과 무기 성능 체감 |

### 세부 규칙
- **난이도 수치**: 봇 스킬 = 기본값 × 배율 + 보정 (쉬움 ×0.7−0.05, 보통 ×1, 어려움 ×1.1+0.12). 사격 반응 시간은 쉬움 1.6배, 어려움 0.7배.
- **보급품**: 투하 고도 190m, 초당 7.5m 하강(약 25초). 착지하면 상자는 엄폐물이 되고 아이템이 주변에 흩어짐. 착지 소리가 260m 안의 봇을 끌어들임.
- 난이도 선택은 브라우저에 저장되어 다음 접속에도 유지됨.
- **스코프**: 레드닷 1.3배, 2배, 4배, 8배. 권총은 장착 불가. 줍으면 현재 들고 있는 주무기부터 더 높은 배율일 때만 자동 장착하고, 기존 스코프는 바닥에 떨굼. DMR·저격총의 기본 조준경(3.2배·5.5배)보다 낮은 배율은 장착하지 않음. 무기를 바꿔 들어도 스코프는 새 무기로 옮겨짐. 무기 이름 옆에 배율 표시.

## v1.2 — 오토 기능 & FPS 편의 기능 (이 PR에 구현)

| 항목 | 조작 | 내용 |
| --- | --- | --- |
| **오토 플레이** | `P` / 모바일 `오토` 버튼 | AI가 캐릭터를 대신 조종(강하·루팅·회복·자기장 이동·교전). 카메라는 AI 시선을 따라감. 다시 누르면 그 자리에서 직접 조작으로 복귀. 사망 시 자동 해제 |
| **자동 사격** | 설정 탭 / 일시 정지 메뉴 | 조준점이 사거리 안의 적에게 닿으면 자동 사격. 단발 무기는 최소 0.22초 간격. 모바일 기본 켜짐, PC 기본 꺼짐 |
| **자동 달리기** | `=` / 모바일 스틱을 위로 길게 끌기 | 손을 떼도 앞으로 달림. PC는 W·S, 모바일은 스틱을 다시 잡으면 해제 |
| **사격 모드 전환** | `B` | 연사 가능한 총(SMG·소총)을 단발로 전환. 무기마다 따로 기억, 탄약 옆에 표시 |
| **기울이기** | `Q` / `E` | 엄폐물 옆으로 몸·카메라·총구를 기울임. 벽에 막히면 덜 기울어짐. 머리 판정도 함께 이동 |
| **자유 시점** | `Alt` 누르고 있기 | 이동 방향은 그대로 두고 카메라만 돌려 주변 확인. 떼면 원래 시점으로 복귀(사격·조준 불가) |
| **핑** | 휠 클릭 | 조준점 위치에 노란 마커와 거리 표시, 미니맵에도 표시. 같은 곳을 다시 찍으면 제거 |
| **소리 방향 표시** | 자동 | 36m 안 발소리(흰 발자국)와 들리는 범위의 총성(주황 화살표)을 조준점 둘레에 방향으로 표시 |

## v1.3 — 조작감 & 화면 정리 (이 PR에 구현)

**조작감**

| 항목 | 내용 |
| --- | --- |
| 아날로그 스틱 | 모바일 이동 스틱을 미는 정도만큼 속도가 변함(살짝 ≈1.9 m/s · 반 ≈3.9 · 끝까지 = 달리기 6.6) |
| 조준 보조(모바일) | 조준점 근처 적에게 시점이 살짝 끌려가고(4° 어긋남 → 1초 뒤 1.5°), 적 위에서는 시점이 덜 미끄러짐. 가림막 너머·사거리 밖 적에는 작동 안 함 |
| 시점 가속 | 손가락을 빨리 밀수록 더 크게 돌고, 천천히 밀면 정밀하게 움직임 |
| 마우스 원시 입력 | 지원 브라우저에서 OS 마우스 가속을 끈 입력 사용 |
| 반응 속도 | 지상 가속 14→20, 무기 교체 0.32→0.22초, 정조준·FOV 전환 더 빠르게 |
| 진동 피드백 | 명중·헤드샷·처치·피격 시 짧게 진동(지원 기기) |

**화면 정리**

- 모바일 상단 버튼은 `Ⅱ · 가방 · 오토` 세 개만. 미니맵을 누르면 전체 지도
- 액션 버튼은 필요할 때만 나타남: 조준(총 들었을 때) · 장전(탄창이 덜 찼을 때) · 무기(2정 이상) · 회복(아이템 있고 다쳤을 때) · 수류탄(있을 때)
- 줍기 버튼은 주울 게 있을 때만, 연사/단발·핑 버튼은 모바일에서 뺌(자동 사격이 기본)
- HUD: FPS 숫자 제거, 킬 로그 최근 3개, 들고 있는 무기·아이템·착용한 방어구만 표시

## v1.4 — 같이 하기(멀티플레이) & 최적화 (이 PR에 구현)

**멀티플레이 (최대 4명 + AI)**

| 항목 | 내용 |
| --- | --- |
| 방 | 4자리 코드·초대 링크(`/?room=CODE`)·열린 방 목록. 방장이 AI 난이도를 고르고 시작 |
| 구조 | Supabase Realtime 브로드캐스트 + 프레즌스, 게임 서버 없음. 방장이 봇·폭풍·보급품을 진행, 각자 자기 캐릭터 진행 |
| 같은 세계 | 매치 시드를 공유해 루트·폭풍 경로·수송기 경로가 모두 같음. 아이템 줍기/떨어뜨리기·사망 루트·보급품은 이벤트로 동기화 |
| 움직임 | 인원에 맞춘 전송 빈도(2명 12회/s ~ 4명 4.5회/s) + 지연 보간으로 부드럽게 재생, 발소리·총구 화염·탄도·명중 효과도 재생 |
| 전투 | 쏜 사람이 명중 판정, 맞은 사람의 클라이언트가 방어구 계산 후 적용. 처치·킬로그는 모두에게 같게 표시 |
| 이탈 | 나간 사람의 캐릭터는 AI가 이어서 조종(이름 뒤에 "(AI)"), 방장이 나가면 다음 사람이 방장 역할 인계 |
| 백그라운드 | 함께 하는 경기는 일시 정지해도 계속 진행, 방장 탭이 숨겨져도 타이머로 시뮬레이션 유지 |

**최적화**

- 로딩 중 캐릭터·장비·루트·수송기·보급품·폭풍·그림자 셰이더를 미리 컴파일 → 경기 중 새 셰이더 컴파일 0개
  (측정: 강하 시작 최악 프레임 110ms → 21ms, 첫 마을 진입 105ms → 11~20ms, 소프트웨어 렌더러 기준)
- 셰이더 오류 로그 동기 조회 끄기(`?debug`일 때만 켬)

## v1.5 — 자연스러운 캐릭터 움직임

절차적 애니메이션(18본 리그 + 2본 IK)의 보행을 새로 만들었습니다.

| 항목 | 내용 |
| --- | --- |
| 발 미끄러짐 제거 | 디딘 발이 몸과 정확히 같은 속도로 뒤로 지나가도록 보폭·박자를 속도에서 계산. 디딘 발 미끄러짐(발 접지점 기준) 조깅 3.9 → 0.3m/s, 걷기 1.5 → 0.4m/s, 앉아 걷기 2.1 → 0.4m/s, 정조준 이동 2.4 → 0.2m/s |
| 걷기 ↔ 달리기 | 걷기는 디딘 다리 위에서 몸이 가장 높고(역진자), 달리기는 디딘 순간 가장 낮고 두 발이 모두 뜨는 구간이 있음. 속도에 따라 자연스럽게 섞임 |
| 발 동작 | 걷기는 뒤꿈치로 디디고 발끝으로 밀어냄(발끝·뒤꿈치를 축으로 회전), 달리기는 뒤꿈치를 높이 차올림. 발끝이 살짝 바깥을 향함 |
| 박자 | 다리 길이로 닿을 수 있는 만큼만 보폭을 늘리고 그 이상은 발걸음이 빨라짐(걷기 약 2.5~3보/초, 조깅 3보/초, 전력 질주 3.5보/초) |
| 상체 | 골반이 앞으로 나가는 다리 쪽으로 돌고 어깨는 반대로 돌아 머리는 수평 유지, 걸을 때 골반이 디딘 발 쪽으로 이동 |
| 팔 | 맨손일 때 반대쪽 다리와 함께 흔들림, 달릴 때 팔꿈치를 굽힘 |
| 반응 | 가속할 때 앞으로 기울고 멈출 때 뒤로, 달리며 방향을 틀면 안쪽으로 기울고, 착지하면 무릎을 굽혀 충격 흡수, 제자리에서 돌면 발을 떼며 돎, 서 있을 때 체중 이동 |
| 앉아 걷기 | 깊은 런지 대신 짧고 빠른 걸음 |

## v1.6 — 배틀그라운드와 다른 플레이 & 걷는 모습 다듬기

**차별화 기능**

| 항목 | 조작 / 조건 | 내용 |
| --- | --- | --- |
| 슬라이딩 | 달리는 중 `C` / 모바일 `앉기` | 즉시 8.4m/s 이상으로 미끄러지며 0.85초 동안 감속, 끝나면 앉은 자세. 슬라이딩 중 `Space`로 일어나며 점프. 1.1초 재사용 대기 |
| 장애물 넘기 | 허리 높이(0.35~1.5m) 앞에서 `Space` | 상자·차·바리케이드 위로 손을 짚고 올라섬. 위에 설 공간이 있을 때만. 막혀서 점프하는 AI도 자동으로 넘음 |
| 현상금 사냥 | 새 안전 구역이 정해질 때 | 2킬 이상 중 가장 많이 처치한 생존자가 표적. 5초마다 위치가 지도에 표시되고 근처 AI가 사냥하러 옴. 처치하면 Lv.3 헬멧/조끼·구급상자·드링크 2·수류탄 |
| 초반 재강하 | 두 번째 폭풍 수축이 끝나기 전 사망 | 결과 화면 대신 재강하 선택. 안전 구역 260m 상공에서 권총·탄약·붕대로 다시 시작, 킬·피해 기록 유지. 매치당 1회 |
| 멀티플레이 | — | 현상금 표적과 재강하가 모든 사람에게 같게 동기화 |

**걷는 모습**

- 경사면: 발마다 실제 지면 높이·기울기를 따라 디디고, 낮은 쪽 발이 닿도록 골반을 내림(경사에 서 있을 때 발과 지면 오차 5.2~5.8cm → 0.2~1.2cm)
- 총 드는 자세: 평소에는 총구를 아래로 낮춰 몸 앞에 들고(로우 레디), 조준·사격·장전하거나 AI가 교전할 때 바로 올림
- 슬라이딩(뒤로 기대 앉아 앞발을 뻗음)·넘기(손 짚고 다리 모음) 전용 자세, 멀티플레이에서도 같은 자세로 보임
